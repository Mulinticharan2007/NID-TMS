# NID-TMS

## Network Intrusion Detection & Real-Time Traffic Monitoring System

### Objective
A Python-based cybersecurity project that monitors network traffic, analyzes packets, detects suspicious activity, and generates security alerts.

### Technologies
- Python
- Scapy
- FastAPI
- Uvicorn
- SQLite
- HTML/CSS/JavaScript
- Git & GitHub

### Main Features
- Network packet capture
- Real-time traffic monitoring
- Traffic analysis
- Port scan detection
- ICMP traffic monitoring
- Suspicious activity detection
- Security alerts
- Web dashboard
- Reports
